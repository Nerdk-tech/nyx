Straight answers

The questions people actually ask.

Can Nyx really build a working app?

Yes. It scaffolds the project, writes the code and runs the build. You get real artifacts: an APK for Android, an IPA for iOS, or an EXE for Windows. Unsigned by default, so add your own signing keys before you ship to a store.

Will it sign into my accounts?

Only the sessions you hand it. Nyx drives a real browser inside your workspace. Credentials stay in that workspace and are never used for training. Revoke access and the session dies with it.

Temporary hosting versus permanent?

Temporary gives you a private URL for preview, up to 24 hours on the free plan. Permanent means Nyx deploys to your own host or domain using your credentials, so the infrastructure stays in your name.

What does unrestricted mean, exactly?

No artificial refusal layer on legitimate work. Nyx will not lecture you about writing a scraper or an automation. It still follows your acceptable use policy and the law, and it will not help with things that harm people.

Can I run it on my own server?

That is what the self hosted runtime is for. Same agent, your hardware, your keys, no per request bill. The managed API is there if you would rather not run infrastructure.
